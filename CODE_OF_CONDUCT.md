# Code Of Conduct / 行为准则

## English

`Rivulet Gateway / 溪流网关` is built as infrastructure software.
That means we optimize for trust, clarity, and steady collaboration over ego or noise.

Our working standard:

- be respectful and technically honest
- critique ideas, designs, and patches without attacking people
- prefer evidence, reproduction steps, and concrete tradeoffs over vague judgment
- help newcomers onboard safely; do not shame basic questions
- keep discussion focused on moving the project toward a dependable production-grade gateway

Unacceptable behavior:

- harassment, intimidation, personal attacks, or discriminatory language
- deliberate disruption of review, testing, release, or community processes
- misrepresentation of benchmark, security, or production-readiness results
- publishing private information without explicit consent

Maintainer expectations:

- apply rules consistently
- explain moderation decisions briefly and concretely
- separate technical disagreement from conduct problems

Reporting:

- for conduct issues, contact project maintainers through the security and governance channels documented in [SECURITY.md](C:\Users\brace\Documents\New%20project\SECURITY.md) and [GOVERNANCE.md](C:\Users\brace\Documents\New%20project\GOVERNANCE.md)

Scope:

- this applies to repository discussions, issues, pull requests, release operations, benchmark result publication, and project communication spaces maintained by the project

## 中文

`Rivulet Gateway / 溪流网关` 是基础设施软件项目。
这意味着我们优先追求信任、清晰和稳定协作，而不是情绪化表达或噪音。

我们的协作标准：

- 尊重他人，并保持技术表达真实
- 可以批评设计、思路和补丁，但不要攻击个人
- 优先给出证据、复现步骤和具体权衡，不做含糊判断
- 帮助新人安全上手，不羞辱基础问题
- 讨论始终聚焦于把项目推进到可信的生产级网关

不可接受的行为：

- 骚扰、威胁、人身攻击或歧视性语言
- 故意破坏审阅、测试、发布或社区协作流程
- 虚报 benchmark、安全性或生产就绪度结果
- 未经明确同意公开他人隐私信息

Maintainer 预期：

- 一致地执行规则
- 对管理决定给出简短且具体的说明
- 把技术分歧和行为问题明确区分

反馈渠道：

- 行为问题请通过 [SECURITY.md](C:\Users\brace\Documents\New%20project\SECURITY.md) 和 [GOVERNANCE.md](C:\Users\brace\Documents\New%20project\GOVERNANCE.md) 中记录的安全与治理渠道联系项目维护者

适用范围：

- 本准则适用于仓库讨论、issue、pull request、发布操作、benchmark 结果发布以及项目维护的沟通空间
